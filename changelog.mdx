<Update label="July 11, 2026" tags={["email","observability","wire"]} description="Email campaigns backend · auth observability">
  **Email campaigns — the full backend layer.** The campaigns domain now runs end to end below the UI: the wire contract and schema reshape ([#244](https://github.com/Sureshmohan19/aasurecompany/pull/244)), campaign and template CRUD routes under the tenant chokepoint ([#245](https://github.com/Sureshmohan19/aasurecompany/pull/245), [#246](https://github.com/Sureshmohan19/aasurecompany/pull/246)), a pure recipient-resolution engine with an estimate endpoint ([#247](https://github.com/Sureshmohan19/aasurecompany/pull/247)), and the studio data layer for Campaigns \+ Templates ([#250](https://github.com/Sureshmohan19/aasurecompany/pull/250)). The plan of record is in [#242](https://github.com/Sureshmohan19/aasurecompany/pull/242).

  **Auth latency observability.** Segmented request timing across biz routes ([#237](https://github.com/Sureshmohan19/aasurecompany/pull/237)–[#239](https://github.com/Sureshmohan19/aasurecompany/pull/239)), auth API timing propagation ([#248](https://github.com/Sureshmohan19/aasurecompany/pull/248)), session-enrichment timing in the api worker ([#249](https://github.com/Sureshmohan19/aasurecompany/pull/249)), plus a latency probe set and recorded findings ([#251](https://github.com/Sureshmohan19/aasurecompany/pull/251), [#252](https://github.com/Sureshmohan19/aasurecompany/pull/252)).

  **Wire.** Domain event contracts for the durable-event work ([#253](https://github.com/Sureshmohan19/aasurecompany/pull/253)).
</Update>
